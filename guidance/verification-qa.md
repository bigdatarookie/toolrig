# verification.qa

Независимый code/affected system review и реальный consumer. Не писать все unit tests за авторов, не обязательный gate каждого PR. Компетентный назначенный неавтор может принять вместо QA окончательное решение. Если существенно исправил код — другой неавтор проверяет эту часть.

Следовать common/TEAM/PLATFORM/EVALUATION в применимом scope, без загрузки всей истории.
